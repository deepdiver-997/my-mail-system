`session_base.tpp` 81%→**92.7%**、`server_base.h` 21.7%→**60.9%**、`mapped_file.h` 74%→**82.1%**。

**测试过程中发现/确认的问题**（未改生产代码）：
- `IOThreadPool::submit()/post()` 是死 API：`post_impl` 空实现（注释掉），任务永不执行、future 永不完成。生产走 `get_io_context()` + asio::post，故测试只测生产路径（`thread_pool_test` 有注记）。
- `fast_fsm_base.h` 不自包含（用了 `SessionBase` 却没 include `session_base.h`），生产靠 include 顺序侥幸编译；测试里先引入 `test_session.h` 规避。
- `pr::ServerConfig::resolve_path` 把 base_dir 当「文件路径」取 parent（与 loadFromFile 传入目录的语义 off-by-one），`server_config_test` 记录了实际行为。
- `IntrusionDetector` LRU 驱逐按秒级 `last_seen`，同秒记录不可区分 → 测试只断言记录数有界。

**仍为零覆盖的 framework 部分**（需真实 TCP/SSL/HTTP，属集成层，留待下轮）：
`connection/tcp_connection.h`、`connection/ssl_connection.h`、`metrics_server.h`（HTTP 端点）、`tcp_server_base.h`（真实 accept）。
